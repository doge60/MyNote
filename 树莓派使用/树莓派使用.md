# 树莓派使用

## 新树莓派到手要做的准备工作

> 树莓派型号：`RasperryPi 4b`

### 安装操作系统

> 我安装的是ubuntu24.24 LTS Desktop（64位）系统。以下步骤应当适用于大部分ubuntu LTS系统。
>
> 如果希望安装其他操作系统，也是使用Raspi Imager向SD卡内刷入相应系统镜像，但刷入后的安装操作需视相应操作系统的实际情况而定。

#### 要准备的东西：

刷入系统阶段：

- 一张32G的SD卡（作为启动盘和存储盘。记得把里面原有的重要文件做好备份，刷入操作系统镜像后，里面原有的所有文件将被全部覆写而消失！）

- 一个读卡器（或者带读卡功能的拓展坞）
- Raspi Imager软件（从树莓派官网下载，用于向SD卡中刷入系统镜像）

安装引导阶段（用于在树莓派上安装系统时，跟随安装向导进行图形化操作）：

- 带miniHDML线的采集卡，或带miniHDML线的屏幕（树莓派只有miniHDML口，想看树莓派的图形化界面就必须得插miniHDML线）
- 键盘和鼠标（用于选择、输入等必要操作）

做好以上准备后，按照Ubuntu官网（[How to install Ubuntu Desktop on Raspberry Pi 4 | Ubuntu](https://ubuntu.com/tutorials/how-to-install-ubuntu-desktop-on-raspberry-pi-4#2-prepare-the-sd-card)）提示操作即可。Raspi Imager向SD卡内刷入系统可能需要等待较长时间。安装引导阶段操作与普通Ubuntu系统安装操作相同。
