> 这里题干并没有明确要求面积是否一定为整数，所以个人认为此题的完整论述中应对此进行讨论。
>
> 通常情况下场地所有者不愿意把自己的场地零散地租出去，租用的场地面积应只能为整数。
>
> 但也有可能允许面积为非整数。
>
> 通过计算发现此题两种情况下得出的结果一样。

求解代码如下（以租用的场地面积应可为非整数（决策变量类型设为Continuous）的情况为例）：

```
import pulp
MyProbLP = pulp.LpProblem("LPExample1_4", sense=pulp.LpMinimize)     # 求最小值

# 设置决策变量
x11 = pulp.LpVariable('x11', lowBound=0, cat='Continuous')
x12 = pulp.LpVariable('x12', lowBound=0, cat='Continuous')
x13 = pulp.LpVariable('x13', lowBound=0, cat='Continuous')
x14 = pulp.LpVariable('x14', lowBound=0, cat='Continuous')

x21 = pulp.LpVariable('x21', lowBound=0, cat='Continuous')
x22 = pulp.LpVariable('x22', lowBound=0, cat='Continuous')
x23 = pulp.LpVariable('x23', lowBound=0, cat='Continuous')

x31 = pulp.LpVariable('x31', lowBound=0, cat='Continuous')
x32 = pulp.LpVariable('x32', lowBound=0, cat='Continuous')

x41 = pulp.LpVariable('x41', lowBound=0, cat='Continuous')

# 设置目标函数
MyProbLP += 2800*(x11+x21+x31+x41)+4500*(x12+x22+x32)+6000*(x13+x23)+7300*x14

# 设置约束条件
MyProbLP += (x11 + x12 + x13 + x14 >= 15)  # 不等式约束
MyProbLP += (x12 + x13 + x14 + x21 + x22 + x23 >= 10)  # 不等式约束
MyProbLP += (x13 + x14 + x22 + x23 + x31 + x32 >= 20)  # 不等式约束
MyProbLP += (x14 + x23 + x32 + x41 >= 12)  # 不等式约束

MyProbLP.solve()
print("Status:", pulp.LpStatus[MyProbLP.status])    # 输出求解状态

# 输出每个变量的最优值
for v in MyProbLP.variables():
    print(v.name, "=", v.varValue)
# 输出最优解的目标函数值
print("Min z = ", pulp.value(MyProbLP.objective))
```
